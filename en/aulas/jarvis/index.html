Lesson 3 · 10 min

Step 2: your Jarvis with INTELECTO

A personal assistant written from scratch in Python, kept small on purpose: it talks with you on Telegram, remembers your conversations, and uses a cloud or local model. You stop opening a website to chat: the assistant is yours.

Start lesson

In this lesson, you will

  1. 1Design the assistant before installing it
  2. 2Create the bot on Telegram
  3. 3Test the memory
  4. 4Choosing between cloud and local

Objective: design, install, and put to work an assistant with memory and a personality you define.

01 · Your assistant’s architecture

From Telegram to the model and back.

Lesson 301 · Your assistant’s architectureFrom Telegram to the model and back.

Scroll down: each step below lights up its part of the diagram.

  1. 1/5

    You

    You chat on Telegram, on your phone or computer, like you would with any contact.

  2. 2/5

    Telegram bot

    The bot is the entry point. You create it with @BotFather using /newbot and store the token only in .env, as you learned in step 1.

  3. 3/5

    INTELECTO

    INTELECTO receives the message, combines your assistant’s personality with what it remembers about you, and puts together the request for the model. It’s small by design, so you can understand and change it.

  4. 4/5

    Model

    The model generates the response. In the cloud (OpenRouter), it’s more powerful and costs money per use; locally (Ollama), it runs on your computer, if it can handle it.

  5. 5/5

    The full conversation

    You write in Telegram, INTELECTO combines personality and memory, the model responds, and the response returns to the same chat. It’s all yours, with the token stored in .env.

02 · From the design to your routine

Click each step.

1. Design

Before installing, write down who the assistant is: its name, how it speaks, three things it should do every week, three things it should never do, and what it needs to remember about you.

This file answers the installation questions.

TestSomeone else reads the file and understands who your assistant is.

2. Create the bot

On Telegram, open @BotFather, send /newbot, and choose a name and @username.

Store the token only in .env.

Step 1 ruleThe token doesn’t appear in any file besides .env.

3. Install

Clone INTELECTO, export your briefing from the comparison page, and ask Claude Code or Codex to build from it and doc/intelecto.md, with tests.

Use the answers in your meu-jarvis.md. The full step-by-step guide is in lesson 4 of the step 2 course.

Done whenYou send "hi" and it replies with the name and style you chose.

4. Memory and routine

Tell it three facts about yourself one day, then ask about them the next day in a new conversation.

Then turn one weekly task into a standing request and use it five days in a row.

Standing requestEvery morning, when I send "day," list my three priorities based on what I told you yesterday.

04 · Practice: the 6 exercises in sequence 2

Prerequisite: complete sequence 1 (terminal, folders, .env).

E1 · Design your Jarvis

15 min

Write the meu-jarvis.md: name, style, what it should do, what it should never do, and what it needs to remember.

Done when: the file fits on one screen, and someone else could understand who your assistant is.

E2 · The Telegram bot

10 min

Create the bot with @BotFather using /newbot and save the token in .env.

Done when: you have the token, and it doesn’t appear in any file except .env.

E3 · Install

30 min

Clone INTELECTO, export the briefing, and ask the agent to build your Jarvis with tests (lesson 4 of the step 2 course).

Done when: you send "hi" and it replies with the name and style you chose.

E4 · Memory test

2 days

Day 1: tell it three facts about yourself. Day 2, in a new conversation: ask about them.

Done when: it remembers without you repeating yourself.

E5 · Cloud or local

20 min

Ask the same question with a cloud-based model (OpenRouter) and a local one (Ollama). Record the time, quality, and cost.

Done when: you can say which model to use for what, based on your own numbers.

E6 · A real routine

20 min

Turn one of the tasks from E1 into a standing request and use it for a week.

Done when: you used it 5 days in a row and noted what to improve.

Full exercises: jornada-agentes/exercicios/02-jarvis.md. The extra challenge (the task list you send before going to bed) is the start of step 3.
